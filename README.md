# Hannah Learning System 1.0

Unified GitHub Pages-ready prototype containing the Hannah Learning System Levels 1–12 framework and the complete interactive **Foundations: The Heart of Hannah** course inside the Foundations Academy.

## Start locally
```bash
python3 -m http.server 8080
```
Open `http://localhost:8080`.

## Foundations integration
- Main system: `/index.html`
- Foundations Academy: choose **Academies → Foundations Academy**
- Interactive Course 1: `/academies/foundations/course-1/index.html`
- The course contains a **Foundations Academy** return link.

## Version 1.0 scope
Course 1 is fully interactive. Course 2 has a curriculum-ready blueprint inside the academy. Courses 3–8 are structured roadmap prototypes. The Medical Academy Levels 1–12 prototype remains available in the main system.

## Production boundary
This remains a front-end prototype. Production requires authentication, secure persistence, role permissions, audit logs, governed content publishing, accessibility testing, and an approved hosting/access model.
