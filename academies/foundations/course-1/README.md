# Hannah Learning System™ — Foundations, Part I (Phase 2)

Complete interactive edition of **Part I: The Heart of Hannah**, including all ten chapters from the approved manuscript.

## Included
- Full Part I manuscript
- Desktop two-page spreads and mobile single-page reading
- Page-turn transitions, contents navigation, bookmarks, and progress memory
- Saved Hannah Reflections
- Interactive Hannah Principles, Decision Framework™, Learning Cycle™, and Team Circle™
- Team Member Oath affirmation
- Part I completion state
- Print / Save PDF edition
- Hannah branding and supplied photography

## Run
Open `index.html` directly, or serve the folder with any static web server.

## Production integration
Replace localStorage calls in `app.js` with Hannah Learning System profile APIs for cross-device progress, reflection storage, oath affirmation, and completion reporting.

## Fonts
The CSS references Teen by family name and uses Georgia as the primary body font. Font files are intentionally not included. Connect Hannah’s properly licensed webfont source in production.

## Printing
Use the **Print / Save PDF** control. The print stylesheet removes navigation and formats each digital page as a clean printable page.
